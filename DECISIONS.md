# PlanetPulse Decision Points

## DP1 — The nudge

When a user crosses the weekly CO₂ target, PlanetPulse shows a prominent, friendly card instead of a warning that shames them. It shows the percentage used and suggests one practical lower-carbon choice for the remainder of the week. This keeps the experience motivating and actionable while still making the target status clear.

## DP2 — Absurd input

PlanetPulse detects unusually high single entries above 10,000 units and opens a confirmation dialog before saving them. The dialog shows the entered quantity and calculated CO₂ amount, then offers **Edit value** or **Continue anyway**. This prevents accidental typos from silently distorting the dashboard, while still allowing legitimate exceptional journeys and marking them as unusual.

## DP3 — The week

PlanetPulse defines a week as Monday 00:00 through Sunday 23:59 in the user’s local time. Dashboard weekly totals and the daily trend chart both use exactly this range, with the current day highlighted. A fixed Monday-first definition makes targets and progress consistent and easy to understand across the app.
